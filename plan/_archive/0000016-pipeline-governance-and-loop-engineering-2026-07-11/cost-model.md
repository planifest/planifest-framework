## Model-Token Cost Drivers (per pipeline run, toggles on)

| Driver | Mechanism | Marginal cost profile | Bound |
|--------|-----------|----------------------|-------|
| P0 completeness loop | Re-evaluating gap checklist per coaching round | Low — checklist evaluation is short | Cap: escalate after 2 rounds on same gap |
| Design-critic (report-only) | 1 fresh-context subagent per P1/P2 exit + consistency script (free, deterministic) | Medium — reads full spec/ADR set once | Cap 3 review-revise iterations when promoted |
| Reversal protocol | Assessor spawn per petition + scoped re-run + cascade re-do | Highest variance — cascade size drives it | Budget 2/feature; cascade list fixed before re-work |
| Ratchet hook | Deterministic diff on artifact writes | ≈ 0 tokens (no model) | n/a |
| Verify-by-execution | Browser/API/CLI observations per criterion at P4 | Medium — proportional to criteria count | Feeds existing P4 cap 5 |
| Cross-model review gate | 1+ fresh-context reviews of the full diff on a second model | Medium-high — full-diff reads | Cap 3 iterations |
| Fine-grained commits/push | Extra git operations | ≈ 0 tokens | n/a |

**Zero-config cost:** all toggles default off — a pipeline run with no toggles enabled adds no token cost over today (NFR-002).

## Assumptions

1. Report-only trial (design-critic on ≥2 features) is run before any loop is promoted — cost incurred deliberately, measured by P8 per-loop iteration counts and token cost (NFR-004)
2. Telemetry ingestion remains within the existing structured-telemetry-mcp arrangement — additive event types add no infrastructure cost
3. Reversal cascades stay small (design intent: scoped delta, not pipeline restart); the cascade-size human gate (Q-003 ADR) bounds the worst case
