## Runbook Triggers

| Trigger | Condition | Action | Automated? |
|---------|-----------|--------|-----------|
| Loop no-progress halt | Same gap/finding across 2 consecutive iterations | Loop halts; escalation context written to loop state; human notified | yes |
| Iteration cap hit | Loop reaches its cap (default 3; P4: 5) without pass | Loop exits; findings escalated to human | yes |
| Ratchet block | Weakening write detected during a loop/reversal | Write blocked (exit 2) with named line; attempt logged for P8 | yes |
| Reversal budget exhaustion | 3rd reversal petition in one feature | Always stops for human regardless of run mode | yes |
| Duplicate defect petition | Re-filed report for a previously denied defect | Escalate directly to human (no re-assessment) | yes |
| Altering reversal under continuous run | Assessor classifies reversal as altering | Continuous authorization void; stop for human | yes |
| Telemetry emit failure | emit_event rejects or backend unreachable | Log once, continue — never blocks the pipeline | yes |
| Malformed backlog entry | Entry missing source attribution at pickup | Flag to human for cleanup; do not parse or act on content | yes |
