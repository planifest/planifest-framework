## Terms

| Term | Definition | Aliases | Used In |
|------|-----------|---------|---------|
| context-mode | An MCP plugin that protects agent context windows by routing large outputs (search results, file analysis, web fetches) through a sandboxed knowledge base. Agents query the index instead of reading raw output. | — | docs/context-mode.md, setup scripts, standard-boot.md |
| routing rules | Instructions that tell an agent to prefer `ctx_*` MCP tools over native tools (Grep, Bash, WebFetch). Advisory — the agent follows cooperatively. Distinct from enforcement hooks, which are hard blocks. | — | docs/context-mode.md, execution-plan.md |
| enforcement hooks | PreToolUse hook scripts (`block-grep.sh`, `block-bash.sh`, `block-webfetch.sh`) registered in `.claude/settings.json` that physically block native tool calls and redirect to ctx_* equivalents. Claude Code only. Hard enforcement — not advisory. | hook scripts, blocking hooks | docs/context-mode.md, setup scripts |
| plugin system prompt | The system instructions injected into the agent's context by the context-mode marketplace plugin when it is installed. Carries routing rules automatically at session start without requiring a separate file. | system-prompt injection | docs/context-mode.md |
| context-mode-agents.md | The routing rules template file previously maintained by planifest and copied to `AGENTS.md` by setup. Superseded by the plugin system prompt. No longer exists in the repository after this change. | routing rules template | plan/current/ (historical only) |
| `--context-mode-mcp` | A flag passed to `setup.sh` / `setup.ps1` that installs context-mode enforcement hooks for Claude Code. After this change, it no longer writes a routing rules file. | context-mode flag | setup.sh, setup.ps1 |
| AGENTS.md | The boot file for Codex (OpenAI). Written by setup for Codex targets. Not a routing rules file. Previously overloaded as a routing rules destination by `--context-mode-mcp`; that overloading is removed by this change. | — | planifest-framework/tool-setup-reference.md |
